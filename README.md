# Slip OCR + QR (ต้นแบบ)

**เวอร์ชัน:** 0.1.0

**อัปเดต:** 10 ตุลาคม 2569 (2026-10-10)

เครื่องมืออ่านข้อมูลจากภาพสลิปโอนเงินไทยในเครื่องด้วย Tesseract.js, ประมวลผลภาพด้วย Sharp และอ่าน mini QR ด้วย jsQR รองรับตัวอย่างจาก K PLUS, กรุงไทย, กรุงเทพ, ไทยพาณิชย์ และ TrueMoney ผลลัพธ์ประกอบด้วยยอด วันที่/เวลา เลขอ้างอิง และชื่อผู้โอน/ผู้รับที่อ่านได้ พร้อมคำเตือนเมื่อข้อมูลไม่ชัดเจน

**ผล OCR และ QR ไม่ใช่หลักฐานยืนยันว่าเงินเข้าบัญชีแล้ว** ระบบนี้ไม่มีการเชื่อมต่อธนาคาร ค่า `verified` เป็น `null` และ `payment_confirmed` เป็น `false` เสมอ ต้องตรวจรายการรับเงินจริงผ่านช่องทางที่ได้รับอนุญาตก่อนยืนยันการชำระเงิน

## เริ่มใช้งาน

ต้องมี Node.js 22 และ npm การใช้งานครั้งแรกต้องเชื่อมต่ออินเทอร์เน็ตเพื่อดาวน์โหลดข้อมูลภาษาไทยและอังกฤษสำหรับ OCR

```sh
cd tools/slip-ocr
npm ci
npm test
```

อ่านภาพสลิปที่อยู่ในเครื่อง:

```sh
npm run read -- "/path/to/slip.jpg" --expected-amount 123.45
```

เปิดหน้าทดสอบในเครื่อง โดยใช้สองหน้าต่างเทอร์มินัลใน `tools/slip-ocr`:

```sh
npm run api
```

```sh
npm run web
```

จากนั้นเปิด `http://127.0.0.1:8766` หน้าเว็บส่งภาพให้ API ที่ `127.0.0.1:8765` และไม่บันทึกภาพที่อัปโหลดลงดิสก์ ไม่ควรเปิดหน้าทดสอบนี้สู่สาธารณะ เพราะไม่มีระบบลงชื่อเข้าใช้

รายละเอียดคำสั่ง API, ตัวแปรแวดล้อม และข้อจำกัดของการอ่านผลอยู่ใน [คู่มือเครื่องมือ](tools/slip-ocr/README.md)

## ข้อมูลส่วนตัว

รีโพนี้เผยแพร่เฉพาะซอร์สโค้ดและคู่มือ ไม่รวมภาพสลิปจริง เอกสารภายใน ไฟล์โมเดลที่ดาวน์โหลด หรือไฟล์ตั้งค่าเฉพาะเครื่อง `.gitignore` จำกัดไฟล์ที่ Git จะเพิ่มได้ตามรายการที่ระบุไว้ หากจะเพิ่มไฟล์ใหม่เพื่อเผยแพร่ ต้องตรวจเนื้อหาและเพิ่มชื่อไฟล์ในรายการนั้นก่อน

## สถานะ
